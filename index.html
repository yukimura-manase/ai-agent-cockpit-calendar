AI Agent Cockpit Calendar

AI Agent Cockpit Calendar is the OAuth app used by the calendar feature of AI Agent Cockpit ("Cockpit").

What the app does

Cockpit is an app that runs on your own computer (such as a Mac) and manages Claude Code sessions. Its calendar feature reads and writes Google Calendar for the Google Accounts you connect:

  • Shows the events of multiple connected accounts on one screen, by week.
  • Calculates your free time between events and copies it as text.
  • Edits and deletes events.

How Google user data is used

  • Cockpit requests the scopes openid, email, https://www.googleapis.com/auth/calendar.events, and https://www.googleapis.com/auth/calendar.calendarlist.readonly.
  • Events and the calendar list are used only to show them on the Cockpit screen and to calculate your free time.
  • The data is stored only on your own computer (~/.claude-cockpit/calendar/). The developer does not run any server for this app and does not receive your data.
  • The data is not shared with or sold to third parties, not used for advertising, and not sent to AI models.
  • You can disconnect an account at any time from Cockpit's calendar screen, or revoke access from your Google Account.

AI Agent Cockpit Calendar's use and transfer of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements.

AI Agent Cockpit Calendar

AI Agent Cockpit Calendar は、AI Agent Cockpit (以下「Cockpit」) のカレンダー機能が使う OAuth アプリです。

アプリでできること

Cockpit は、利用者のコンピューター (Mac など) の中で動き、Claude Code のセッションを管理するアプリです。カレンダー機能は、利用者が連携した Google アカウントの Google カレンダーを読み書きし、次のことを行います。

  • 連携した複数のアカウントの予定を、1 つの画面に週ごとに表示します。
  • 予定の間の空き時間を計算し、文字列としてコピーします。
  • 予定を編集・削除します。

Google のユーザー データの使い方

  • Cockpit が求めるスコープは、openid、email、https://www.googleapis.com/auth/calendar.events、https://www.googleapis.com/auth/calendar.calendarlist.readonly の 4 つです。
  • 予定とカレンダーの一覧は、Cockpit の画面への表示と、空き時間の計算にだけ使います。
  • データは利用者のコンピューターの中 (~/.claude-cockpit/calendar/) にだけ保存します。このアプリのためのサーバーを開発者は持っておらず、データを受け取りません。
  • データを第三者に提供・販売せず、広告に使わず、AI のモデルに送りません。
  • 連携は、Cockpit のカレンダーの画面からいつでも解除できます。Google アカウントからもアクセスを取り消せます。

AI Agent Cockpit Calendar が Google API から受け取った情報の使用と転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。

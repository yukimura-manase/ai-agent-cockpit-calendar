Privacy Policy

AI Agent Cockpit Calendar
Effective date: October 29, 2026

1. About this policy

This policy describes how the OAuth app "AI Agent Cockpit Calendar" handles Google user data. The OAuth app is used by the calendar feature of AI Agent Cockpit ("Cockpit"), an app that runs on your own computer (such as a Mac) and manages Claude Code sessions. The calendar feature shows the events of the Google Calendar accounts you connect on the Cockpit screen, lets you edit and delete events, and calculates your free time.

2. Permissions (scopes) requested and what they are used for

ScopeUse
openid, emailTo get the email address of the connected Google Account, so that Cockpit can tell which account is connected.
https://www.googleapis.com/auth/calendar.eventsTo list events (for display), update events (when you edit them), and delete events (when you delete them). Cockpit does not create new events.
https://www.googleapis.com/auth/calendar.calendarlist.readonlyTo get the list of your calendars (name, color, and your access role). Cockpit only reads this list and does not change it.

3. How the data is used

  • Events and the calendar list are used only to show them on the Cockpit screen and to calculate your free time.
  • Fetched events are cached in the memory of the Cockpit server for 60 seconds, per account and date range. The cache is discarded when you edit or delete an event. The "Reload" button on the screen fetches the events again from Google without using the cache. Event contents are not written to files.
  • When you press "Copy" for your free time, Cockpit puts text that contains only dates and times into your clipboard. Event titles and other event details are not included.
  • Access tokens are kept only in memory.
  • Cockpit does not write refresh tokens or event contents to its logs.

4. Where the data is stored

  • The data that Cockpit stores is kept only on your own computer, in ~/.claude-cockpit/calendar/ (the default location). The folder is created with permissions that only the owner can access (0700), and the files with permissions that only the owner can read and write (0600).
  • The stored files are:
    • accounts.json: for each connected account, the email address, the refresh token, the granted scopes, the time it was connected, and the connection status.
    • oauth-client.json: the OAuth client information that you place in Cockpit.
  • The developer does not run any server for this app and does not receive your Google user data. For the calendar feature, Cockpit communicates only with Google (accounts.google.com, oauth2.googleapis.com, and www.googleapis.com).
  • The Cockpit server listens only on 127.0.0.1. If you turn on Cockpit's phone connection or multiple-PC feature, Cockpit sends events to the devices that you paired or registered yourself, in order to show them on those devices' screens.

5. Sharing and transfer

  • Google user data is not shared with or sold to third parties.
  • Google user data is not used for advertising.
  • Google user data is not sent to AI models (including AI agents such as Claude Code), and is not used to train AI models.
AI Agent Cockpit Calendar's use and transfer of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements.

6. Disconnecting and deleting your data

  • When you press "Disconnect" for an account on Cockpit's calendar screen, Cockpit asks Google to revoke the refresh token, and deletes the information about that account stored on your computer (such as the email address and the refresh token). It also discards the access token and the cached events in memory. Even if the revoke request fails, the information on your computer is deleted. In that case, please revoke access in your Google Account as described below.
  • You can also revoke the access of AI Agent Cockpit Calendar from "Third-party apps & services" in your Google Account.
  • To delete all the calendar data that Cockpit stores, delete the folder ~/.claude-cockpit/calendar/.

7. Changes to this policy

When this policy changes, this page is updated and the date of the change is added below the effective date at the top.

8. Contact

For questions about this policy, please open an issue in the GitHub repository of this site.

プライバシー ポリシー

AI Agent Cockpit Calendar
制定日: 2026 年 10 月 29 日

1. このポリシーについて

このポリシーは、OAuth アプリ「AI Agent Cockpit Calendar」による Google のユーザー データの扱いを定めます。この OAuth アプリは、AI Agent Cockpit (以下「Cockpit」) のカレンダー機能が使います。Cockpit は、利用者のコンピューター (Mac など) の中で動き、Claude Code のセッションを管理するアプリです。カレンダー機能は、利用者が連携した Google アカウントの Google カレンダーの予定を Cockpit の画面に表示し、予定の編集・削除と、空き時間の計算を行います。

2. 求める権限 (スコープ) と用途

スコープ用途
openid、email連携した Google アカウントのメール アドレスを取得し、どのアカウントを連携したかを見分けます。
https://www.googleapis.com/auth/calendar.events予定の一覧の取得 (表示)、予定の更新 (編集)、予定の削除に使います。Cockpit は予定を新しく作りません。
https://www.googleapis.com/auth/calendar.calendarlist.readonlyカレンダーの一覧 (名前・色・利用者の権限) を取得します。一覧は読むだけで、変更しません。

3. データの使い方

  • 予定とカレンダーの一覧は、Cockpit の画面への表示と、空き時間の計算にだけ使います。
  • 取得した予定は、アカウントと期間ごとに、Cockpit のサーバーのメモリに 60 秒キャッシュします。予定を編集・削除したときは、キャッシュを捨てます。画面の「再読み込み」では、キャッシュを使わずに Google から取り直します。予定の内容はファイルに保存しません。
  • 空き時間の「コピー」を押すと、Cockpit は日付と時刻だけの文字列をクリップボードに入れます。予定の件名などの内容は入れません。
  • access token はメモリにだけ持ちます。
  • Cockpit は、refresh token と予定の内容をログに書きません。

4. 保存先

  • Cockpit が保存するデータは、利用者のコンピューターの中の ~/.claude-cockpit/calendar/ (既定の場所) にだけ置きます。フォルダーは所有者だけが開ける権限 (0700) で、ファイルは所有者だけが読み書きできる権限 (0600) で作ります。
  • 保存するファイルは次の 2 つです。
    • accounts.json: 連携したアカウントごとの、メール アドレス・refresh token・許可されたスコープ・連携した日時・連携の状態
    • oauth-client.json: 利用者が Cockpit に置いた OAuth クライアントの情報
  • このアプリのためのサーバーを、開発者は持っていません。開発者は利用者の Google のユーザー データを受け取りません。カレンダー機能で Cockpit が通信する相手は、Google (accounts.google.com、oauth2.googleapis.com、www.googleapis.com) だけです。
  • Cockpit のサーバーは 127.0.0.1 だけで待ち受けます。利用者が Cockpit のスマホ接続や複数の PC の機能を有効にした場合は、利用者自身がペアリング・登録した端末の画面に予定を表示するために、その端末へ予定を送ります。

5. 共有と転送

  • Google のユーザー データを第三者に提供・販売しません。
  • Google のユーザー データを広告に使いません。
  • Google のユーザー データを AI のモデル (Claude Code などの AI エージェントを含む) に送りません。AI のモデルの学習にも使いません。
AI Agent Cockpit Calendar が Google API から受け取った情報の使用と転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。

6. 連携の解除とデータの削除

  • Cockpit のカレンダーの画面でアカウントの「解除」を押すと、Cockpit は Google に refresh token の取り消しを求め、利用者のコンピューターに保存したそのアカウントの情報 (メール アドレスや refresh token など) を消します。メモリ上の access token と予定のキャッシュも捨てます。取り消しの要求が失敗しても、コンピューターの中の情報は消します。この場合は、次の方法で Google アカウントから取り消してください。
  • Google アカウントの「サードパーティ製のアプリとサービス」からも、AI Agent Cockpit Calendar のアクセスを取り消せます。
  • Cockpit が保存したカレンダーのデータをすべて消すには、フォルダー ~/.claude-cockpit/calendar/ を削除します。

7. 改定

このポリシーを変えるときは、このページを書き換え、冒頭の制定日の下に改定日を書きます。

8. 問い合わせ先

このポリシーについての問い合わせは、このサイトの GitHub リポジトリの Issues に書き込んでください。
